# 踩坑记录

开发过程中真实踩到的问题，每条都写了「现象 → 根因 → 解决」，避免重复踩。

---

## 1. 中文字全显示成框框

**现象**：像素农场界面所有中文变成 `□□□`。

**根因**：`generate_assets.py` 里字符集扫描列表是**硬编码**的：

```python
files = ["badge_ui.c", "wifi_panel.c", "wifi_service.c",
         "ble_service.c", "wallpaper_service.c", "apps.c"]
```

新增的 `pixel_farm.c`、`analog_clock.c`、`weather.c` 不在列表里，它们的中文字符根本没进字模。

**解决**：把新应用文件加入扫描列表，且**只提取双引号字符串字面量**（避免把注释里的中文也打进字模，浪费 Flash）。

字符集从 413 → 438 字形。

**教训**：新增任何含中文的 `.c` 文件，都必须同步更新字模生成脚本的扫描列表。

## 2. 字体编译报 20 位溢出

**现象**：

```
assets.c:27: error: unsigned conversion from 'int' to 'unsigned int:20'
changes value from '1049899' to '1323' [-Werror=overflow]
```

**根因**：LVGL 的 `lv_font_fmt_txt_glyph_dsc_t.offset` 字段只有 **20 位**，上限 **1,048,575**（1 MiB）。字号 f56 加字后 bitmap 偏移达到 1,120,739，溢出。

**量化数据**（修复前最大偏移）：

| 字号 | 最大 offset |
|---|---|
| f14 | 63,132 |
| f18 | 113,481 |
| f24 | 183,362 |
| f36 | 405,581 |
| **f56** | **978,891** ← 加 27 个新字后变 1,120,739 溢出 |

**解决**（两个方向都做了）：

1. **按字号分池**：新应用用的字只加入 `size <= 36`，f56 保持基础池
2. **直接删掉 f56**：它只被开屏名片页使用，而名片页为了腾 Flash 已经删了

```python
base_chars = set(chars)      # 先快照基础池
chars |= app_chars           # 再合并新应用字
# 生成时：只有 size <= 36 才用合并后的 chars
```

> ⚠️ 注意顺序：`base_chars` 快照**必须**在 `chars |= app_chars` **之前**，否则快照已含新字，f56 仍然溢出。（第一次就写反了，白编一轮。）

**教训**：字体不是"字越多越好"，大字号 bitmap 增长快，20 位偏移是硬上限。

## 3. ARGB8565 在 LVGL 9.4 上不能用

**现象**：准备用 `LV_COLOR_FORMAT_ARGB8565`（3 字节/像素）做透明树木动画，省 1/4 空间。

**根因**：查 `lv_color.h` 发现官方注释：

```c
LV_COLOR_FORMAT_ARGB8565 = 0x13,   /**< Not supported by sw renderer yet. */
```

**软件渲染器不支持**，用了会花屏。

**解决**：只能用 `ARGB8888`（4 字节/像素）。原本 32 帧树只要 576 KiB，实际需要 **768 KiB**，只好把雨雪特效从 4 帧减到 2 帧来补缺口。

**教训**：算 Flash 时带透明通道的图一律按 4 字节/像素估，别幻想 3 字节。

## 4. 屏幕上有两棵树（一静一动）

**现象**：阴天时右侧出现两棵树重叠——一棵静止，一棵在摆。

**根因**：素材包的 `backgrounds/weather_overcast_360.png` 里**烘焙了一棵静态樱花树**（x≈290–360, y≈180–300），而四季背景用的是 `*_tree_free_360.png`（已挖掉树）。阴天切到那张图，就和叠加的动画树撞了。

**验证**：逐张看图确认——8 张四季背景（白天 4 + 夜晚 4）全部干净无树，**只有阴天那张有树**。

**解决**（走了两步，第一版是错的）：

| 方案 | 做法 | 结果 |
|---|---|---|
| ❌ 错误 | 阴天时隐藏动画树 | 用户要的是"树始终会动"，藏起来是反的 |
| ✅ 正确 | **删掉阴天背景图**，阴天改用「当季背景 + 灰蓝滤镜」 | 保住季节感 + 动画树，还省 253 KiB |

```c
// 阴雨雪：当季背景叠灰蓝滤镜，晴天不加
lv_obj_set_style_image_recolor(wx_bg_img, lv_color_hex(0x8090B0), 0);
lv_obj_set_style_image_recolor_opa(wx_bg_img, wx_gloomy ? 110 : 0, 0);
```

`opa` 取值：0 = 原色，255 = 全灰，110 ≈ 43% 混合。

**教训**：

1. 素材文件名里的 `tree_free` 必须逐张验证，不能只看名字
2. 分层素材（背景/树/特效）混用不同批次的图时，要确认每张图的"已烘焙内容"

## 5. 天气一直"更新失败"，但时间正常

**现象**：WiFi 连上了，时间显示了，天气一直失败。

**根因**：和风天气**无条件返回 `Content-Encoding: gzip`**，即使请求头写 `Accept-Encoding: identity` 也照样压缩。`esp_http_client` **不会自动解压**，297 字节的 gzip 二进制直接喂 `cJSON_Parse()` → 返回 NULL。

**验证**：

```bash
curl -s -D- -o /dev/null 'https://<host>/v7/weather/now?location=101210101&key=***'
# 输出里始终有 Content-Encoding: gzip
```

**解决**：加 `gunzip_if_needed()`，按魔数 `1F 8B` 判断，用 zlib 的 `inflateInit2(&s, 15+32)` 自动识别 gzip 头：

```c
#include "zlib.h"

static int gunzip_if_needed(char *buf, int len, size_t cap)
{
    if(len < 2 || (uint8_t)buf[0] != 0x1f || (uint8_t)buf[1] != 0x8b)
        return len;                     // 明文，原样透传

    static char plain[4096];
    z_stream s = {0};
    s.next_in = (Bytef *)buf;  s.avail_in  = len;
    s.next_out = (Bytef *)plain; s.avail_out = sizeof(plain);
    if(inflateInit2(&s, 15 + 32) != Z_OK) return -1;
    int rc = inflate(&s, Z_FINISH);
    inflateEnd(&s);
    if(rc != Z_STREAM_END || s.avail_out == 0) return -1;

    int out = sizeof(plain) - s.avail_out;
    memcpy(buf, plain, out);
    return out;
}
```

实测：297 字节 gzip → 448 字节明文 → `code=200, 16°C, Overcast`。

**教训**：嵌入式 HTTP 客户端默认不解压，遇到服务端强制 gzip 必须自己处理；同时要把失败原因打到屏幕上（`请求失败/解压失败/解析失败`），否则只能盲猜重编。

## 6. CMake 找不到 json / zlib 组件

**现象**：

```
CMake Error: Failed to resolve component 'json'
```

**根因**：ESP-IDF 6.1 **没有内置** `json` 和 `zlib` 组件，它们由托管组件提供，名字带前缀。

**解决**：

```cmake
REQUIRES ... espressif__cjson espressif__zlib ...
```

**教训**：IDF 6.x 里第三方库基本都是 `espressif__` 前缀的托管组件，不是内置的。

## 7. 删应用后编译报 `fluidbox.h: No such file`

**现象**：把 Grok / FluidBox / 模拟时钟从应用列表删掉后，`build.ps1` 里也把头文件从复制列表移除，编译立刻失败：

```
fatal error: ui/fluidbox.h: No such file or directory
```

**根因**：**系统文件仍在 include 并调用已删应用的接口**：

| 文件 | 调用 |
|---|---|
| `main.c` | `fluidbox_mode()`、`fluidbox_reset()`（USB 命令分发） |
| `management.c` | `fluidbox_info()`（状态 JSON 上报） |
| `motion_service.c` | `fluidbox_motion()`（姿态数据转发，4 处） |

**解决**：

1. 已删应用的**头文件保留在复制列表**（头文件不占 Flash）
2. 在 `apps.c` 里补空 stub
3. `xxx_info()` 必须返回**合法 JSON**——`management.c` 会直接 `cJSON_Parse` 它，非法内容会让整个状态上报接口挂掉

```c
void fluidbox_motion(const int16_t xyz[3], bool available){(void)xyz;(void)available;}
void fluidbox_mode(int mode){(void)mode;}
void fluidbox_reset(void){}
void fluidbox_info(char *out, size_t size){
    if(out && size) snprintf(out, size, "{\"removed\":true}");
}
```

**删应用前先查调用方**：

```bash
grep -rn 'include.*\(要删的头文件\)' usb_screen/device/src/*.c ui/*.c
```

**教训**：删应用不是只改 `apps.c`——`build.ps1` 的复制列表、`CMakeLists.txt` 的 SRCS、系统侧调用点，三处都要过一遍。

## 8. 编译卡在 `Reading CMake configuration...`

**现象**：日志停在 21 行不动，看起来像死机。

**根因**：两种情况都可能，要区分：

1. **PowerShell 输出缓冲** —— 实际在跑，只是日志没刷出来
2. **IDF Component Manager 联网校验组件索引卡住** —— 网络抖动就挂

**判断方法**：看 staging 目录文件数是否在增长，而不是看日志行数。

```bash
S=$(ls -dt F:/CABadgeBuild/staging/*/usb-screen-*/build-*/ | head -1)
find "$S" -newermt '-3 minutes' -type f | wc -l   # 有增长 = 在跑
```

**解决**：

```bash
export IDF_COMPONENT_CHECK_NEW_VERSION=0   # 跳过版本联网检查（缓存已完整）
```

组件缓存位置：`F:\CABadgeBuild\platformio\idf61\.cache\components`（约 95 MB）。

**教训**：不要因为日志不动就杀进程——先看文件数/CPU，我因为这个误杀过一次正常编译。

## 9. `°` 和 `↻` 显示成框框

**现象**：温度 `16` 后面的度数符号是框；右上角刷新图标是带叉的框。

**根因**：

- **`°` (U+00B0)**：温度用 `font36`，但字模分池只给 `size <= 24` 加了应用字符，f36 里没有 `°`
- **`↻` (U+21BB)**：字符在 unicode 列表里，但 **NotoSansSC 源字体本身没有这个字形**，fonttools 导出空 glyph

**解决**：

- `°`：字模分池条件从 `size <= 24` 改为 `size <= 36`
- `↻`：换成中文「刷新」，用 `font14`（字形确定存在）

**教训**：特殊符号要先确认**源字体有没有该字形**，再考虑字模子集；不要假设字符在 unicode 表里就能显示。

## 10. 运行时 A8 图层的染色

**做法**：雨雪特效帧只有 alpha 通道（不透明像素占比 1.8–3.6%），用 `LV_COLOR_FORMAT_A8`：

```c
lv_obj_set_style_image_recolor(wx_fx, lv_color_hex(kind == WX_ICON_RAIN ? 0xAFCBEE : 0xFFFFFF), 0);
lv_obj_set_style_image_recolor_opa(wx_fx, LV_OPA_COVER, 0);
```

在 A8 格式下，`recolor` 就是**可见像素的显示颜色**（见 `lv_draw_image.h:61`）。

这样 8 帧雨雪只要 1 MiB 而不是 4 MiB（ARGB8888）。

## 11. 字模/素材是生成产物，别手改

`ui/assets.c`（2.5 MB）、`ui/weather_assets.c`（8.5 MB）、`ui/pixel_farm_assets.c`（1.2 MB）都是脚本生成的 C 数组。

改素材或改中文文案后必须重跑：

```bash
python firmware/tools/generate_assets.py            # 字模
python firmware/tools/generate_weather_assets.py    # 天气素材
python firmware/tools/generate_pixel_farm_assets.py # 农场素材
```

直接手改这些文件，下次生成会被覆盖。
