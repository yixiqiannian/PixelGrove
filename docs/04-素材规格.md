## 3. 颜色格式（转换后）

固件里用三种格式，由 `generate_weather_assets.py` 负责转换：

| 用途 | LVGL 格式 | 字节/像素 | 说明 |
|---|---|---|---|
| 背景（360×360） | `LV_COLOR_FORMAT_RGB565` | **2** | 不透明，无 alpha |
| 图标、树木 | `LV_COLOR_FORMAT_ARGB8888` | **4** | 需要柔和透明边缘 |
| 雨雪特效 | `LV_COLOR_FORMAT_A8` | **1** | 只有 alpha，颜色靠运行时染色 |

> **ARGB8565（3 字节）不可用** —— LVGL 9.4 明确标注 `Not supported by sw renderer yet`，
> 用了会花屏。详见 [05-踩坑记录 §3](05-踩坑记录.md)。

### 尺寸换算

| 类别 | 单张大小 | 张数 | 合计 |
|---|---|---|---|
| 背景 360×360 RGB565 | 259,200 B | 8 | 2.02 MiB |
| 树木 64×96 ARGB8888 | 24,576 B | 32 | 768 KiB |
| 雨雪 360×360 A8 | 129,600 B | 4 | 506 KiB |
| 图标 48×48 ARGB8888 | 9,216 B | 6 | 54 KiB |
| **合计** | | | **约 3.3 MiB** |

## 5. ⚠️ 阴天背景的陷阱

`01_背景/原始包/weather_overcast_360.png` **自带一棵静态樱花树**（x≈290–360, y≈180–300）。

如果把它当"无树背景"用来叠动画树，屏幕上会出现**两棵树重叠**。

**当前方案**：这张图**已从固件移除**（省 253 KiB），阴天改用「当季背景 + 灰蓝滤镜」：

```c
lv_obj_set_style_image_recolor(wx_bg_img, lv_color_hex(0x8090B0), 0);
lv_obj_set_style_image_recolor_opa(wx_bg_img, wx_gloomy ? 110 : 0, 0);
```

**其余 8 张四季背景已验证干净无树**（逐张看图确认，不只看文件名）。

## 6. 树木动画要求

| 项 | 值 |
|---|---|
| 尺寸 | 64×96 |
| 每季帧数 | 4 |

| 冬 | 光秃枝干 + 枝头积雪 |

## 7. PNG → C 数组的转换

`firmware/tools/generate_weather_assets.py` 的转换规则：

```python
# 背景：缩放到 360×360，转 RGB565
def rgb565_dsc(name, img):
    img = img.convert("RGB").resize((360, 360), Image.LANCZOS)
    data = img.tobytes("raw", "BGR;16")   # LVGL RGB565 小端字节序

# 图标/树木：保留 alpha，转 ARGB8888
def argb_dsc(name, img):
    data = img.convert("BGRA").tobytes()

# 雨雪：只取 alpha 通道
def a8_dsc(name, img):
    alpha = img.convert("RGBA").getchannel("A")
    data = alpha.tobytes()
```

生成的 C 数组：

```c
const lv_image_dsc_t wx_bg[8] = { &wx_bg_spring, ... };
const lv_image_dsc_t *const *const wx_trees[8] = {
    wx_tree_day_spring, wx_tree_day_summer, wx_tree_day_autumn, wx_tree_day_winter,
    wx_tree_night_spring, wx_tree_night_summer, wx_tree_night_autumn, wx_tree_night_winter
};
const lv_image_dsc_t *const wx_icons[6] = { ... };
const lv_image_dsc_t *const wx_rain[2] = { ... };
const lv_image_dsc_t *const wx_snow[2] = { ... };
```

> **数组索引顺序必须与 `ui/weather.h` 里的枚举一致**，改顺序会错位。

## 8. 素材变更后的流程

1. 替换 `assets/` 里的 PNG
2. 改 `firmware/tools/generate_weather_assets.py` 顶部的素材源路径（指向 `assets/`）
3. 运行脚本重新生成 `ui/weather_assets.c`
4. 重新编译烧录

**不要手改** `ui/weather_assets.c`（8.5 MB 的生成产物），下次生成会被覆盖。
