# 规格说明

## 1. 硬件规格

| 项 | 规格 |
|---|---|
| 开发板 | DFRobot **DFR1221** |
| 主控 | ESP32-S3R8 |
| 内核 | 双核 Xtensa LX7 @ 240 MHz |
| Flash | **16 MB**（QIO，40 MHz） |
| PSRAM | **8 MB Octal**（`CONFIG_SPIRAM_MODE_OCT=y`） |
| 屏幕 | **ST77916**，QSPI @ 40 MHz |
| 屏幕分辨率 | **360 × 360**（圆形可见区，四角被裁剪） |
| 触摸 | 电容触摸，坐标域 360×360，无独立 RST / INT 引脚 |
| 无线 | WiFi 2.4 GHz + BLE |
| 供电 | USB-C |
| 调试 | USB-CDC 串口（`COM6`，无普通 UART 日志） |

### QSPI 引脚

定义在 `firmware/device/src/physical_display.c`：

```c
spi_bus_config_t bus = ST77916_PANEL_BUS_QSPI_CONFIG(9, 11, 12, 13, 14, 360*32*2);
```

对应：时钟 9 / 数据 11,12,13,14（换板需改此处）。

## 4. 像素天气应用规格

### 4.1 页面结构（3 页，左右滑动切换）

| 页 | 内容 |
|---|---|
| **主页面** | 城市名、当前温度（font36）、天气图标 + 天气文字、今日最高/最低、当前时间日期、数据更新时间、右上角「刷新」按钮 |
| **未来三天** | 每天：日期、星期、图标、天气文字、最高/最低 |
| **详情页** | 湿度、风力（风向+等级）、气压、能见度、体感温度 |

- 所有文字与触摸目标位于圆屏可见区内，信息多时分页而非堆叠
- 返回：左上角 `‹` 按钮
- 刷新：右上角「刷新」按钮（中文，因为源字体缺 `↻` U+21BB 字形）

### 4.2 数据字段映射

来自和风天气 `/v7/weather/now`：

| 接口字段 | 用途 |
|---|---|
| `now.temp` | 主温度 |
| `now.icon` / `now.text` | 天气图标与文字 |
| `now.humidity` | 湿度 |
| `now.windDir` / `now.windScale` | 风向、风力等级 |
| `now.pressure` | 气压 |
| `now.vis` | 能见度 |
| `now.feelsLike` | 体感温度 |

来自 `/v7/weather/3d`：

| 字段 | 用途 |
|---|---|
| `daily[0].tempMax/tempMin` | 今日最高/最低 |
| `daily[0].sunrise/sunset` | **昼夜判断**（不是设备时区） |
| `daily[1..2]` | 未来两天 |

### 4.3 天气图标映射

`icon_kind()` 把和风天气 icon code 归到 6 种：

| 条件 | 图标 |
|---|---|
| `400 ≤ code < 500` | `WX_ICON_SNOW` 雪 |
| `300 ≤ code < 400` | `WX_ICON_RAIN` 雨 |
| `code == 100` 或 `150` | `WX_ICON_SUN` 晴 |
| `101–103` 或 `151–153` | `WX_ICON_PARTLY` 多云 |
| 其余（含 104 阴、雾霾等） | `WX_ICON_CLOUD` 阴 |

未识别的 code 一律回退到阴天图标，不会崩溃。

### 4.4 季节判定

```c
// 优先用 WX_SEASON_OVERRIDE 强制
if(WX_SEASON_OVERRIDE >= 1 && WX_SEASON_OVERRIDE <= 4)
    return WX_SEASON_OVERRIDE - 1;

// 否则按查询城市当地月份（北半球）
3–5 月 → 春(0)   6–8 月 → 夏(1)
9–11 月 → 秋(2)  12–2 月 → 冬(3)
```

月份取自**接口时区换算后的当地时间**，不是设备时间。

### 4.5 昼夜判定

```c
int now_min = lt->tm_hour * 60 + lt->tm_min;
if(有日出日落数据 && sunset > sunrise)
    return now_min >= sunrise && now_min < sunset;
return now_min >= 6*60 && now_min < 18*60;   // 兜底
```

优先用接口返回的日出日落；缺失时兜底 6:00–18:00。

### 4.6 背景与树木选择逻辑

```c
if(夜晚)     背景 = 四季夜景图[si]          树 = 夜晚树[si]
else         背景 = 四季白天图[si]          树 = 白天树[si]
             若为雨/雪/阴 → 再叠加灰蓝滤镜
```

| 背景数组 | 文件 |
|---|---|
| `wx_bg[0..3]` | 春/夏/秋/冬 白天（`*_tree_free_360.png`） |
| `wx_bg[4..7]` | 春/夏/秋/冬 夜晚（`*_night_tree_free_360.png`） |

| 树木数组 | 内容 |
|---|---|
| `wx_trees[0..3]` | 白天 春/夏/秋/冬，各 4 帧 |
| `wx_trees[4..7]` | 夜晚 春/夏/秋/冬，各 4 帧 |

**阴/雨/雪不切换背景图**，而是给当季背景加滤镜：

```c
lv_obj_set_style_image_recolor(wx_bg_img, lv_color_hex(0x8090B0), 0);
lv_obj_set_style_image_recolor_opa(wx_bg_img, wx_gloomy ? 110 : 0, 0);
```

> 原因：素材包里那张 `weather_overcast_360.png` **自带一棵静态樱花树**，会和动画树重叠。
> 详见 [05-踩坑记录](05-踩坑记录.md)。

### 4.7 树木动画

- 尺寸 64×96，ARGB8888（带透明通道）
- 位置：屏幕坐标 **(257, 207)**（左上角）
- 帧率：**450 ms/帧**，4 帧循环
- 始终显示（含阴雨雪），仅在切换到不同树组时重置帧序

### 4.8 刷新与容错策略

| 参数 | 值 | 宏 |
|---|---|---|
| 自动刷新间隔 | 20 分钟 | `WX_REFRESH_SEC 1200` |
| 手动刷新节流 | 60 秒 | `WX_MANUAL_MIN_SEC 60` |
| 失败退避起点 | 40 秒 | `WX_RETRY_BASE_SEC 40` |
| 退避上限 | 20 分钟 | `WX_RETRY_MAX_SEC 1200` |
| HTTP 超时 | 10 秒 | `WX_HTTP_TIMEOUT_MS 10000` |

**失败处理**：

- 保留上次成功数据，界面标注「更新失败」或「离线」+ 最后更新时间
- 首次无数据 → 显示占位符，**不把 0°C 当实况**
- 失败原因上屏：`请求失败` / `解压失败` / `解析失败` / `接口xxx` / `数据缺失`

**线程模型**：

- 网络请求在独立 FreeRTOS task 中执行，通过队列把结果投递给 GUI task
- 不阻塞 UI
- 退出应用时置 abort 标志，丢弃在途结果，停止动画定时器

## 5. 像素农场规格

- 触摸操作：种植 / 浇水 / 收获
- 作物：胡萝卜、萝卜，各有 4 个生长阶段
- 状态持久化到 NVS
- 依赖 SNTP 校准时间（未校准时提示「时间未校准」）
- 自带全屏背景与返回键
